# Research Governance

可审计、证据保真的 Research/Due-Diligence vertical。保护 canonical claims、conflict sets、source refs 和 final evidence binding，阻止多 Agent handoff 静默丢失反证。

独立启动：`npm start`。统一 Gateway 路径 `/v1/research/*`。dev.3 已通过 `@ppl/platform-execution` 接入 Retrieval、OpenAI-compatible LLM transport 与 bound-delivery semantic Judge；外部具体模型仍需部署侧 live probe。
