# PPL 产品化迁移路线与验收

## R0 — Product Boundary

状态：**完成**。

首个 Research Governance 闭环：evidence → governed handoff → fidelity → evidence-bound delivery → audit。

## R1 — Packaging, Persistence & Multi-Vertical Split

状态：**完成**。

已实现：

- 根目录 `npm ci --offline` 一次安装全部产品层依赖；
- SQLite reference store；
- revision conflict / idempotency / exactly-once event boundary；
- Session/Audit/Evidence repositories；
- 重启恢复；
- 通用 Agent Governance vertical；
- Research vertical；
- Tutor vertical；
- Life / Personal Assistant vertical；
- Character / NPC vertical；
- Unified Platform Gateway；
- Stable component source identity 验证。

R1 的关键设计决定：**部署统一，业务模型独立。**

## R2 — Real Host / Retrieval / Judge Integration

状态：**完成（Generic Agent + Research 主路径）**。

已实现：

- OpenAI-compatible local model transport；
- HTTP JSON / SearXNG retrieval；
- Stable Host transport resilience 与 Host-owned ToolExecutionLedger；
- Generic Agent governed model execution；
- model tool request → Host allowlist/execute → continuation；
- Research evidence extraction / Analyst / Reviewer / bound-delivery Judge；
- model/Judge independence group；
- localhost real HTTP end-to-end qualification；
- deployment-side live probe。

资格边界：构建环境没有外部模型 endpoint，因此没有声明具体 Qwen/vLLM/LM Studio live-qualified。Tutor/Life/Character 的 LLM generation adapter 仍保持独立后续任务，不以 Generic/Research schema 强行统一。

## R3 — Observatory Product UI

把旧 Observatory 收敛成多 vertical 只读 Console，至少能查看 Session、Audit、Evidence/State、Handoff/Fidelity 和 Delivery。

## R4 — External Agent Runtime Adapters

LangGraph 作为首个正式 adapter；Execution Graph 和 Authority Graph 始终分离。增加 omission、polarity flip、confidence inflation、provenance loss、task mutation 等 fault injection。

## R5 — Stable Candidate

必须同时满足 clean install、persistent restart、real LLM/Judge qualification、multi-agent fault injection、read-only audit UI、security boundary 文档和无已知 P0 blocker。
